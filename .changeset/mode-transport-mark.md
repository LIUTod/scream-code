The mark after the permission mode in the input box says how far the mode lets the agent run, and what it is doing: AUTO `▸▸` (all the way), YES `▸` (stops only for the high-risk few), ASK `‖` (reads, never changes), BOT `↻` (works on its own). While the agent works the arrows flow and BOT turns; while it waits on you (an approval or a question) the badge shows `‖` in the warning colour, breathing, so the stop is seen where you type. It replaces the same `✎﹏` for every mode. With motion off the marks hold still.
