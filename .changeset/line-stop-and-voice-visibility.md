IM channels gain an interrupt and lose their silent gaps. `/stop` aborts the turn that is running right now via the new `LineSessionDriver.stopActiveTurn()` — the aborted turn suppresses its own reply so the chat is not told twice — and it is the one command that is not blocked while busy. A message that lands behind a running turn now answers immediately with `收到，前面还有 N 条在处理中。回复 /stop 可中止当前任务。` instead of waiting in silence. Voice support is probed once at startup (`ffmpeg -encoders`, looking for AMR-NB) and reported in `/status`, so a missing encoder is visible before the first fallback-to-file, and every submitted voice message logs that the gateway's `ret: 0` is not a delivery receipt — that log line is the only trace the platform gives. `/cancel` stops and starts a fresh session, and a `/stop` that cannot settle within 10 s closes the live session without deleting it, so the next message resumes the same session id — the same end result as tearing down the agent process. Shutdown now waits up to 60 s with a printed notice instead of cutting a turn after 10 s, the resolved `workDir` is printed at startup (warning when the config omits it), and daemon console lines carry ISO timestamps.
