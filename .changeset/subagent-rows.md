A subagent is a row of the turn's block instead of a card of its own, so a foreground subagent no longer sits below the block while it runs. While it works, the line under its row says what it is doing now ("正在使用 Read …/config/index.ts"); Ctrl+O lists its steps; when it finishes the row reads done with its tool count and time. Several subagents of one step are rows side by side. A run handed to the background keeps its running mark rather than a success tick. The subagent's activity line is now in the session language instead of always English.
