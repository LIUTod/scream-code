Usage accounting: auxiliary requests — side questions (`/btw`), knowledge-base extraction / rerank / entity recall, exit memory extraction, skill planning and goal grading — now record their usage under the session alias (session scope), so `/usage` and the session token limit see them; before, none of them were counted. Goal grading now goes through the same `generateWithRetry` seam as the other auxiliary calls instead of `rawGenerate`, which had bypassed secret obfuscation (the graded output can carry secrets), OAuth resolution, request logging and transient-error retries. Pricing resolves usage keys — which are model *aliases* — through the alias to the catalog model it names (`priceForUsageKey`), so a hand-named alias such as `my-fast` → `vendor-chat` is priced in `/usage` instead of showing as unpriced. A subagent fold now records the child's cumulative usage (`fold`) on its `usage.record`, and replay merges it into the session fold ledger with an element-wise max: a child resumed after a process restart folds only what it accrued since, instead of its whole history a second time, and replaying the same record again (a middle agent evicted and re-hydrated in the same process) can no longer double the ledger and make the child's next fold under-count.

CLI copy follows the locale. `scream --help`, option-conflict errors, `-p` messages, `scream export`, `scream line` status and the update prompt were hard-coded Chinese; they now go through `t()` with English and Chinese entries, so an English environment (`LANG=en_*`) gets English output; once a language has been saved with `/language`, the saved choice wins over `LANG` for `--help` and option errors too (they are printed before the config is loaded the usual way). Engine-side messages the model or the user sees — compaction notices, the Storm Breaker loop guard, the working-set and session-state reminders, `MemoryWrite` output, the LSP install hint, FusionPlan angle labels and the MCP needs-auth error — are now English, matching the rest of the engine and the system prompt.
