When `run_in_background=true`, the subagent runs detached from this turn and its result arrives in a later turn as a synthetic user-role message — do not poll, sleep, or check on its progress, and never fabricate or predict what it will say.

While it runs it can reach you via `ContactParent` (delivered at your next step boundary), and a `SendSubagentMessage` reply steers it mid-run; a foreground subagent's questions end your wait and hand it to the background the same way. When `timeout` is omitted, a background task falls back to the operator-configured background timeout if one is set — with none configured it runs with no time limit.
