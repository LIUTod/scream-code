# @scream-code/config

## 0.20.0

### Minor Changes

- [`151b05d`](https://github.com/LIUTod/scream-code/commit/151b05d4f6feb4c316eb367fa546b6d4826ced79) - A fired scheduled task now also surfaces on the status row above the editor, not only as a transcript block. The chip follows the shared grammar: `⏰ 定时任务已触发：<preview>` — with `（合并 N 次）` when several fires collapsed into one delivery, `⏰ 一次性提醒已触发：…` for a one-shot task, and `⚠️ 定时任务已过期，仍触发：…` in the warning colour for a task past its 7-day cutoff. The prompt preview is sanitized and capped at 40 characters because it is model-authored text written into a terminal row. The reminder owns its own slot (10s TTL) drawn to the left of the collaboration ticker (8s), so a help request can neither evict a fired reminder nor outlive it, and a narrow terminal truncates the ticker first. Both chips are dropped together when the session switches.

- [`041bc86`](https://github.com/LIUTod/scream-code/commit/041bc862d5aadca77bd04635e475f887f4f942c5) - The footer is now two fixed rows. Line 1 keeps identity: model name, provider balance and the working-tree git summary, with the context gauge right-aligned as `📨 Context：<bar> <percent>` (slim `▰▱` bar, 10/6/0 cells at >=68/>=52/<52 columns, floored with at least one lit cell for non-zero usage; the whole gauge shares one semantic colour). Line 2 starts with the cache hit rate, then the plan/rlm/wolfpack mode badges, the goal badge and background-task badges, with the channel readout `◆ Line: <Lark|Wechat|未连接> <work status>` right-aligned (only the dot is coloured; line 2 shrinks its left side first). The status row above the editor now uses one chip grammar: `⚠️ 重连中 n/max：reason · delay`, `🤝 name 求助：issue` / `✓ Scream 已处理 name 的请求`, and the idle hint in the theme's dim colour instead of a hardcoded grey.

  Subagent-to-parent collaboration requests no longer cut into the transcript. A delivered request surfaces as a one-line ticker above the editor — `coder is asking Scream for help: <preview>` — replaced by the newest event and echoed as `Scream handled the request from coder` once the main agent answers it. The request body stays in the parent's context and in the agent card's tool-call arguments. This removes the unreachable activity-pane component, the unused loader colour setter and the duplicate status-bar spinner branch, and stops the pulse-wave timer chain on shutdown.
